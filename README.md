# 🐸⚡ Tode the Frog: Cyber Swamp Survivors

A 3D rogue-lite action survivor game built for the **#JetBrainsGameChallenge**.

👉 **[🎮 PLAY THE LIVE GAME HERE (Desktop & Mobile)]((https://tode-cyber-swamp-survivors.vercel.app/))**

---

## 🚀 What Was Extended From the Base Course
- **Rogue-Lite Level-Up System:** Added XP progression and 6 rarity-coded cyber augmentation cards (*Split Plasma, Overclocked Synapse, Mega Watt Croak, Hydraulic Legs, Ricochet Pulse, Nano-Lily Core*).
- **3 Enemy Archetypes & Wave Pacing:** Added Scout Gnats (Wave 1 easy tutorial), Armored Beetles, and Spitter Wasps.
- **Phase Dash Mechanic:** Added an invulnerable dash with particle bursts and live cooldown HUD.
- **Cross-Platform Controls:** Works on Desktop (`WASD` + Mouse/Auto-Aim) and Mobile (360° Virtual Touch Joystick + Touch Dash button).
- **Cyber-Swamp Glassmorphic UI & Procedural Audio:** Custom neon HUD, floating damage numbers, and 100% procedural Web Audio API sound effects.
